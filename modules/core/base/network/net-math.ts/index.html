    NetVec (type alias)

    Dimension-agnostic vector/rotation helpers the correction helpers share. A 2D world's positions are Point2 and rotations plain angles; a 3D world's are Point3 and quaternions - every function here tells them apart at runtime (z present / rotation is a number) and dispatches to Pnt2/Pnt3/Qtrn, so one algorithm serves both. Internal to the network helpers, not re-exported from the package root.

    Signature

    export type NetVec = Point2 | Point3
