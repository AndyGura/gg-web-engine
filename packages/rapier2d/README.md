## [Rapier.js](https://github.com/dimforge/rapier.js) 2D integration for [gg-web-engine](https://github.com/AndyGura/gg-web-engine), providing 2D physics simulation

### Installation:
1) make sure **@gg-web-engine/core** installed
1) `npm install --save @gg-web-engine/rapier2d`
